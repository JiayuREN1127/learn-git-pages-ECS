# Git / GitHub / GitHub Pages / ECS 10 分钟入门

这是一份面向社会科学专业同学的项目演示材料。它不假设你有计算机基础，目标是在 10 分钟内用清楚、自然、可视化的方式说明四个常见工具：

- **Git**：记录项目变化，像一份可以回退的研究日志。
- **GitHub**：把项目放到线上，方便保存、展示和协作。
- **GitHub Pages**：把 GitHub 仓库里的内容发布成网页。
- **ECS / CVM 云服务器**：租一台一直在线的云端电脑，运行网站、程序或数据服务。

## 适合谁

- 第一次听说 Git、GitHub、服务器的同学。
- 想把课程项目、研究资料、个人主页发布到网上的同学。
- 想理解“代码仓库”“网页部署”“云服务器”这些词到底在说什么的同学。

## 10 分钟路线

| 时间 | 内容 | 一句话理解 |
| --- | --- | --- |
| 0:00-1:00 | 为什么要学 | 项目资料需要可追踪、可协作、可展示 |
| 1:00-3:00 | Git | 记录每一次修改，随时回到过去 |
| 3:00-5:00 | GitHub | 把项目放到线上，别人也能看和参与 |
| 5:00-7:00 | GitHub Pages | 把仓库变成一个公开网页 |
| 7:00-9:00 | ECS / CVM | 租一台云端电脑，运行更复杂的服务 |
| 9:00-10:00 | 怎么选择 | 静态展示用 Pages，动态服务用 ECS |
